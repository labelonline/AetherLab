# AetherLab — Release Management Update

Это обновление добавляет связанную систему управления релизами без аналитики и без расширения финансового раздела.

## Что добавлено

- **Release Hub 2.0**: обзор релиза, треки, детальная модерация, доставка и история релиза.
- **История релиза**: автоматически фиксируются создание/сохранение черновика, отправка и повторная отправка на модерацию, изменения основных данных/обложки/аудио, решение модератора и изменения статуса доставки.
- **Детальная модерация**: обложка, основные данные, название, исполнитель, трек-лист, аудиофайлы, авторы/композиторы, Explicit, язык, Lyrics/TTML и AI-маркировка. Copyright-раздел не добавлялся.
- **Календарь релизов**: месяц и список. Администратор видит доступные ему релизы всех кабинетов, артист — свои. На телефоне календарь автоматически превращается в компактный список.
- **Artwork Checker**: формат изображения, 3000×3000, 1:1 и лимит 10 MB.
- **Audio Checker**: проверка структуры WAV, каналов, sample rate, bit depth и лимита 50 MB. Это техническая проверка, а не оценка мастеринга/качества звука.
- **Activity Log**: журнал действий для администратора с фильтрами и поиском. Записи журнала не редактируются из интерфейса.
- **Глобальный центр уведомлений удалён**: колокольчик и popup-уведомления больше не используются. Локальные индикаторы поддержки/разделов сохранены.
- **Удаление релизов администратора отключено**: в интерфейсе нет раздела удалённых релизов, а старые функции удаления/восстановления заблокированы.

## Новые данные Firebase

Существующие релизы могут получить поля:

- `history` — история конкретного релиза;
- `moderation` — детальная проверка модератора;
- `distribution` — ручной статус доставки.

Также используется корневой узел `activityLog` для общего журнала администратора. Если текущие Firebase Rules не разрешают запись в `activityLog`, Release Hub и история конкретного релиза продолжат работать, но часть глобальных записей журнала не будет сохраняться между устройствами до изменения Rules.

## Совместимость

Старые релизы не мигрируются и не изменяются автоматически. Для них Release Hub показывает, что подробная история начинает формироваться с этого обновления. Новые действия будут добавляться дальше автоматически.

## Развёртывание

Загрузите **содержимое** папки `AetherLab-main` в корень репозитория AetherLab с заменой совпадающих файлов. Новый `index.html` использует версию ресурсов `20260930-rm2`, чтобы браузер не держал старые JS/CSS после обновления.
